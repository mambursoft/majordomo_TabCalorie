## Призначення

TabCalorie — інформаційний плагін для локального контролю споживання
вуглеводів за даними застосунку «Таблиця калорійності»
(`tablycjakalorijnosti.com.ua` / `kaloricketabulky.cz`) у системі MajorDoMo.
Плагін призначено для контролю харчування, обмежень і норм споживання та
формування звітності.

## Треті сторони

- «Таблиця калорійності» / Dine4Fit — власність відповідних розробників.
  Плагін використовує внутрішній JSON API лише для читання даних користувача за
  його явними обліковими даними. Жодних офіційних партнерських відносин не існує.
- Nightscout — проєкт з відкритим кодом; плагін використовує його API за
  бажанням користуватора (опційно, вимкнено за замовчуванням).
- Іконка плагіна (`img/tabcalorie.svg`, `img/modules/tabcalorie.png`) —
  оригінальний малюнок, створений для цього проєкту; не є копією чужого логотипа.

## Персональні дані

Автор не має доступу до персональних даних користувачів. Усі дані зберігаються
локально в інсталяції MajorDoMo користувача. Репозиторій не містить реальних
логінів, паролів, токенів чи персональних даних користувача.
